# Operating System Synchronization

## Project Title
Synchronization of Readers-Writers and Dining Philosophers Problems Using Semaphores and Monitors in Java with HTML Playback of Events

## Description
This project implements two classic Operating System synchronization problems using Java. Both problems are implemented using semaphore-based and monitor-style synchronization approaches.

## Problems Implemented
1. **Readers-Writers Problem**
   - Semaphore approach
   - Monitor approach

2. **Dining Philosophers Problem**
   - Semaphore approach
   - Monitor approach

## Technologies Used
- Java
- Semaphores
- ReentrantLock and Conditions
- HTML, CSS, and JavaScript

## Features
- Thread synchronization and mutual exclusion
- Event recording and tracking
- HTML-based event playback and animation
- Comparison of semaphore and monitor approaches

## Project Report
The complete project report is included in this repository as a PDF file.

## Conclusion
This project demonstrates how semaphores and monitors can be used to coordinate concurrent threads and manage shared resources in Operating Systems.
